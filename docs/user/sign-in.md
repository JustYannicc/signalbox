# Sign in

When your Signalbox server has accounts turned on, signing in is the first
thing every app asks for. You can sign in with Google, GitHub, Apple, or an
email address, using a password or a one-time code. There is no separate
sign-up step: the first time you continue with an account, it is created.
The first time you use some providers, such as GitHub, Signalbox emails you a
code to confirm your address.

## On each app

- **Web**: choose an option on the sign-in page.
- **Desktop**: choose **Sign up** or **Sign in**. Signalbox opens your browser,
  so your password manager and saved logins work there. If you are already
  signed in in that browser, it sends you straight back. When the browser asks
  to open Signalbox, allow it.
- **Mobile**: enter your server's address if the app asks for it, then pick an
  option. A server without accounts sends you to pairing instead.

## Signing out

On web and desktop, sign out under **Settings → General → Account** or from
the command palette. On mobile, open the environment under **Settings →
Environments** and choose **Sign out**, which also removes it from the phone.

Signing out ends that device's session only. Your browser may still remember
your account, so the next sign-in shows an account picker where the provider
supports one.

If your server does not have accounts turned on, you connect devices by
[pairing](./remote-access.md) instead.
